# श्रीमद्भागवत कथा महोत्सव – Website

Premium Hindi, mobile-responsive event invitation website for the Bhagwat Katha at ग्राम एकों, जिला जालौन (01–08 February 2027).

## Files
- `index.html` – all event content and sections
- `styles.css` – responsive saffron, antique-gold and deep-maroon design
- `script.js` – mobile navigation and Google Form embed
- `config.js` – paste your published Google Form URL here
- `assets/` – optimized invitation and kathavachak photographs
- `google-apps-script/Code.gs` – creates the RSVP Google Form and linked response sheet
- `SETUP.md` – Google Form and GitHub Pages instructions

See `SETUP.md` for setup and publishing steps.
